#### Минутка теории
`F1` представляет собой гармоническое среднее точности и полноты классификатора. Таким образом F1 убывает почти линейно при убывании точности или полноты, давая возможность эффективно учитывать оба фактора.

`F1 = 2 * precision * recall / (precision + recall)`, где `precision = TP/(TP+FP)`, `recall = TP/(TP+FN)`

Каппа Коэна позволяет измерить точность (`accuracy`) алгоритма с поправкой на вероятность получить подобную точность случайным образом, что является существенным при преобладании одного из классов.

`Cohen’s kappa = (p_o - p_e) / (1 - p_e)`, где `p_o` - наблюдаемая доля согласия (`accuracy`), а `p_e` - ожидаемая доля случайного согласия `(TP + FP) * (TP + FN) + (FN + TN) * (FP + TN) / N ** 2`

Худший результат показывает `SVC`, который желательно тьюнить для такой задачи (RBF - ядро штука хорошая, но простая). Логистической регрессии просто сложно выразить взаимодействие между 100 скорелированных признаков, LogReg можно использовать как довесок к другому эффективному алгоритму. Случайный лес и градиентный бустинг показывают примерно одинаковое качество так как оба хорошо приспособлены для работы с табличными данными, возможно, для того чтобы продемонстрировать превосходство градиентного бустинга следует брать другой набор дескрипторов. Ансамбль тоже сработал хорошо (т.к. это простой способ без особых раздумий повысить качество модели, еще лучше на нем бустинг запустить, правда может переобучиться), несмотря на то, что его результаты значительно подрортил SVC (от которого я изначально ожидал лучших результатов, поэтому и добавил в эксперимент).
