# ДЗ 5-6
ДЗ выполнено в двух файлах: main.py, содержащий код с выполненными заданиями для дескрипторов RDKitDescriptors, и main_full.py, который содержит код для полных дескрипторов с фингерпринтами Моргана и MACSS ключами (т.к. RDKit-дескрипторов не много, что ухудшает работу ML алгоритмов и снижает осмысленность feature-selection).

При запуске кода использовался Python 3.12 с помощью менеджера проектов UV ([https://docs.astral.sh/uv/](https://docs.astral.sh/uv/)). Инструкции по установке UV можно найти на [сайте](https://docs.astral.sh/uv/) (например, установить командой `curl -LsSf https://astral.sh/uv/install.sh | sh`). Далее окружение синхронизируется командой `uv sync` (после чего образуется директория окружения - `.venv`).

После синхронизации окружения код можно запустить командами `uv run main.py` или `uv run main_full.py` (долго). При создании скриптов результаты были перенаправлены в файлы `main.log` и `main_full.log`, соответственно.

Далее подробнее описаны результаты скрипта `main.py`.

При импутации NaN заменяются на медиану по соответсвующему признаку, что позволяет минимизировать влияние выбросов и скошенных распределений.
